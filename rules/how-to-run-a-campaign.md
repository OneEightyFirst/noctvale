# How to Run a Campaign


A campaign is a linked series of **10 battles**, then ends. Each player keeps the same retinue between battles, tracks injuries and XP, sells recovered **Relics**, and spends **Crowns** to replace losses or expand the roster.

Start a new campaign retinue with **1000 Crowns** using the [retinue building rules](retinue-building.md). Record **Roster Cost** on the roster sheet.

After each battle, resolve the **Post-Game Sequence** in order. Scenario rewards come first, then casualties, companion recovery, Doom results, Survival Rolls, economy, and advancement.
